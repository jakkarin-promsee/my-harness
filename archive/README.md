| Folder | What it is | Rule |
|---|---|---|
| `mvp/` | The Stage-1 single-file harness — the learning artifact. Its `fixtures/stats.py` carries a bug **on purpose** (acceptance task C) and `ACCEPTANCE.md` + fixtures still serve the live gate. | **Frozen — do not modify.** |

| `prompt/` | The owner's **real prompt library** from months of research work (plan / run-overnight / summarize / compact / clean). This is the raw material Stage 3.2 turns into structured templates. | **Read-only reference — precious.** |
